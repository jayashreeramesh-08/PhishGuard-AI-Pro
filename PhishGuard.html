About PhishGuard AI Pro

PhishGuard AI Pro is an advanced phishing URL detection system developed by Team 4-SQUAD for Project Expo 2K26.

The system uses an ensemble of Random Forest and Logistic Regression models to analyze 24 URL features with 94.7% accuracy.

Features

  • 🧠Explainable AI Risk Scores
  • 🔗URL Behavior Analysis
  • 🌍Community Threat Sharing
  • 💾Persistent Local Database
  • 🎤AI Voice Assistant with Voice Responses

How to Use

  • 1URL Scanner: Enter URL → Click ANALYZE → View risk score
  • 2Voice Assistant: Click robot button → Type or use microphone 🎤 → Get voice responses
  • 3Community: Report suspicious URLs to help others
  • 4Database: Search, filter, and export your scan history
